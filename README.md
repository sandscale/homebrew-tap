# Sandscale Homebrew tap

```sh
brew install sandscale/tap/sandscale
sandscale --version
sandscale login
```

`Formula/sandscale.rb` installs the Sandscale CLI from its [releases](https://github.com/sandscale/cli/releases) on macOS
(Apple silicon and Intel) and Linux (x64 and arm64), each download checked against its SHA-256.

Upgrade with `brew upgrade sandscale`. Other ways to install: https://github.com/sandscale/cli
